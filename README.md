### What I learned

Another instance where I encapsulated the <header> element within <main>. It works for me, but not sure if I could frame this better and keep the aesthetics I'm after...

```html
<main class="card">
      <img class="card__image" alt="a qr code image" src="./images/image-qr-code.png" />
      <header class="card__info">
        <h1 class="card__title">
          Improve your front-end skills by building projects
        </h1>
        <p class="card__text">
          Scan the QR code to visit Frontend Mentor and take your coding skills
          to the next level
        </p>
      </header>
    </main>
```
